# SimpleNet-CBAM-PatchGuard

## 项目说明

本项目为本科毕业设计《基于 SimpleNet 的无监督图像异常检测算法设计与实现》的相关代码与实验整理。项目面向工业图像异常检测任务，在轻量判别式框架 SimpleNet 的基础上进行改进，构建 SimpleNet-CBAM-PatchGuard 模型。

该方法通过引入 CBAM 注意力机制增强异常相关特征表达，并借鉴 PatchGuard 的鲁棒思想，对判别特征层进行稳健约束，以减弱噪声与离群特征对模型判别过程的影响。项目主要用于实现工业图像的图像级异常检测与像素级异常定位，并在 MVTec AD 数据集上完成相关实验验证。
